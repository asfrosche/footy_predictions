System overview

Footy Predictions is a read-only web application. A FastAPI server loads seven JSON data files, turns them into fixtures, standings, group tables, market odds and team profiles, and serves them as JSON under /api. The same server hosts a static site (HTML, CSS and vanilla JavaScript) that calls the API and renders the results in the browser. Nothing is written back to storage, and no user accounts or database are involved.

  • Backend FastAPI 0.116, Uvicorn, Python 3.12
  • Frontend Static HTML, CSS and JavaScript, no build step
  • Data Seven JSON files in data/
  • Tests pytest suite in tests/test_api.py

P

Process

Key stages and workflows

  1. Load dataRead JSON once and cache it · data.load_json
  2. Normalise fixturesMerge completed and upcoming lists into one shape · data.all_matches
  3. FilterApply competition, status and team filters · data.matches_for
  4. Compute tablesPoints 3/1/0, then goal difference and goals scored · data.compute_standings
  5. Remove marginTurn decimal odds into percentages that sum to 100 · data.implied_probabilities
  6. Assemble profilesClub or national view for one team · data.team_profile
  7. ServeJSON under /api, site at /, page at /sipoc · app/main.py
  8. Render in browserFetch, escape and draw each view · static/js/app.js

Steps 1 to 7 run on the server. Step 8 runs in the visitor's browser.

What this analysis cannot verify

  • Where the match, odds and team data originally came from, and how often it refreshes.
  • Whether the data is accurate. The app shows what the files contain.
  • The last_updated and generated_at dates, which are stored values and not checked against a live source.
  • Whether the app is deployed anywhere, and at which address.

Not present in this code

  • Predictions from the match engine. The earlier fifa_data/ engines were not copied, so the site shows market odds and approximations only.
  • Data fetching, scheduled refresh and provider integrations.
  • Accounts, a database and any write operation.
